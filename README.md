# Interactive-Math-Trainer

**About the project:**
The aim of this project is to help users improve their mathematical skills by identifying their weaknesses in specific operations and providing focused practice. Morespefically, This is a Python-based program that allows users to practice different operations such as addition, subtraction, multiplication, division, powers, and square roots at different difficulty levels.

The program tracks users to practice various operations, tracks scores, streaks, correct and incorrect attempts, and exports performance statistics to a CSV file for reviewing progress and identifying areas for improvement. This helps users strengthen their weaker skills and develop better problem-solving abilities in mathematics.

**Features:**
* Mathematical operations:
  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Powers
  * Square Roots

* Different difficulty levels:
  * Single-digit
  * Double-digit
  * Triple-digit

* Tracks user performance, including:
  * Score
  * Correct answers
  * Wrong answers
  * Best streak

* Saves performance statistics into a CSV file for users to review their progress.

**Libraries used:**
* Random
* CSV
